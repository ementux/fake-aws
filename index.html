Úkoly pro tebe 🧪

  1. Přihlas se na server přes SSH. 
    ssh -i demo-key.pem -p 2200 root@localhost
  2. Zeptej se serveru, kdo je. Každá EC2 instance má speciální adresu 169.254.169.254, na které zjistí informace o sobě. Právě odtud jsou údaje nahoře. 
    TOKEN=$(curl -s -X PUT http://169.254.169.254/latest/api/token -H "x-aws-ec2-metadata-token-ttl-seconds: 60")
curl -s -H "x-aws-ec2-metadata-token: $TOKEN" http://169.254.169.254/latest/meta-data/instance-id
    NápovědaZkus místo instance-id třeba instance-type nebo placement/availability-zone.
  3. Změň tuhle stránku. Na serveru uprav nadpis a obnov prohlížeč. 
    sed -i 's/Ahoj ze serveru/Ahoj od [tvoje jméno]/' /srv/www/index.html
  4. Zboř a postav znovu. Spusť terraform destroy a pak terraform apply. Změnilo se Instance ID? Proč?
    OdpověďAno. Každá nová instance dostane nové ID. Infrastruktura jako kód znamená, že server umíme kdykoli zahodit a vytvořit stejný znovu.
